# OneShot Developer Tools (мод)

Мод добавляет в игру меню **Developer Tools** (открывается клавишей **F9**
на карте или через «Параметры → Developer Tools») с инструментами
для тестирования и отладки.

## Установка

Скопируйте файл `Data/xScripts.rxdata` из релиза в папку `Data/` игры
OneShot с заменой. Перед заменой сделайте резервную копию оригинального
`xScripts.rxdata`.

## Возможности

| Пункт меню | Что делает |
|---|---|
| Teleport | Список всех карт игры, телепорт с сохранением координат |
| Hitboxes (Sunshine) | Оверлей проходимости: непроходимые тайлы подсвечены красным |
| Noclip | Прохождение сквозь стены, эвенты и любые препятствия |
| Show Events | Оверлей: жёлтые маркеры и id всех эвентов на карте |
| Start Event | Список эвентов текущей карты, запуск выбранного эвента |
| Debug Menu (Switches/Vars) | Редактор свитчей и переменных одной кнопкой |
| Goto Debug Room | Быстрый телепорт в отладочную локацию |
| Speed Up | Увеличенная скорость передвижения |
| Reset Game | Сброс на титульный экран (сейвы не трогаются) |
| Reset Game + Delete Save | Сброс с удалением сохранений и их бэкапов (настройки и язык сохраняются) |

Дополнительно:

- Новая настройка **April Fools mode** в «Параметрах»: первоапрельская
  секретка активна всегда.
- В левом верхнем углу карты отображаются активные читы и пометка
  `CHEATS USED`.

## Внимание: достижения Steam

Мод выставляет предупреждение `CHEATS USED` при использовании читов.
Не используйте читы в прохождении, где важны достижения Steam.
